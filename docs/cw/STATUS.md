# CW-Diffusion 开发状态（2026-11-17）

开发分支：`method/canonical-world-diffusion`。使用入口：`./mvwd cw --help`；完整配置和运行说明见 [README](README.md)。

## 已实现

- RGB BEV 预测对象、完整三维姿态和不确定性；对象局部 Gaussian 特征场、共享外观随机变量、背景与机器人支撑。
- 三个独立 FLUX 原生视角流，通过可微 Gaussian 渲染、几何注意力和零初始化输出交换信息。
- 噪声感知 MVS、受限几何更新、跨步持久世界记忆；每个视角的外观更新排除自身当前及历史写入，CFG 两个分支独立。
- 语义、实例、对象布局、深度、可见射线自由空间、冻结 DINO 特征、表面对应和实例区分监督，以及完整两步训练展开。
- 独立环境与实验目录；四卡 BF16、梯度累积和原生块激活检查点；完整 optimizer/RNG 续训；推理三视角原子保存与续跑。

默认实现是完整方法。没有启动轻量模型对照、故意缺陷版本或消融训练。

## 真实数据审计

数据集共 23,285 个 episode，50 个场景；训练/验证/测试分别为 18,597 / 1,350 / 3,338。语义词表为 253 类；提供视角与 BEV 实例掩码、场景实例目录、对象状态/姿态/世界 AABB、深度和 BEV 高度/占据。场景实例 ID 需要通过目录映射，不能跨场景直接当作全局身份；ID 1/2/3 为三个机器人。目录中最大对象数为 1,328，默认对象查询数为 1,536。

没有核实到完整不可见三维占据、规范纹理图或材质 BRDF 标签。因此自由空间只使用有效观测射线，外观使用冻结特征目标。测试生成不读取这些监督。50 场景审计检查代表文件的模态清单，真实解码验证使用训练样本；并非全量原始文件完整性审计。

## 比较时必须披露

新方法使用额外的训练监督，并继承已完成的 FLUX 10 epoch 权重；默认再训练 10 epoch。它与只训练一次的 baseline 不属于相同总预算。冻结训练教师与 MV 指标属于同一 DINO 家族，需要结合图像质量及独立几何检查解释结果。输出保留原 baseline 的 256×448 完整 FOV、固定测试帧和三个随机种子协议。

当前交付为完整方法的实现与 CPU 验证，不能据此认定架构最优、H100 必然装得下或质量已有提升。
